# Shubhika — Artisanal Indian Festive Gifting & Hampers

A polished, contemporary, premium landing page for an Indian festive gifting brand offering handcrafted mithai, royal dry-fruit hampers, heritage farsan, and curated keepsake boxes.

## Features & Sections
- **Top Announcement Bar**: Slim festive banner with NRI gifting and seasonal notice.
- **Sticky Navbar**: Brand wordmark, smooth section anchor navigation, shopping bag badge, and mobile drawer.
- **Cinematic 3D Hero Section**: Layered focal showcase of celebratory trunks with interactive tilt effect, ambient gold lighting, and primary/secondary CTAs.
- **Shop by Category**: Highlighting Artisanal Mithai, Royal Dry Fruits, Heritage Farsan, Bespoke Gift Boxes, and Grand Celebration Hampers.
- **New Arrivals**: Interactive category filter, detailed product cards with pricing and piece/weight specs.
- **GlowCard Spotlight Effect**: Custom pointer-following radial spotlight with warm antique gold glow (`src/components/ui/spotlight-card.tsx`), responsive to motion preferences and touch devices without blocking button clicks.
- **Festive Bestsellers**: Distinct presentation with gift-box ribbon and GlowCard spotlight integration.
- **Brand Story**: Split layout communicating pure A2 ghee culinary craftsmanship, small-batch recipes, and philosophical heritage.
- **Why Choose Us**: Refined icon markers for purity, curated boxes, varied budgets, reliable delivery, and global card processing.
- **Corporate Gifting**: Dedicated section for institutional orders with custom logo foil-stamping and a working frontend modal with form validation.
- **NRI / Send Gifts to India**: Warm copy addressing patrons abroad sending festive gifts to families in India with global card payments.
- **Patron Testimonials**: Editorial carousel featuring quotes from both domestic and international patrons.
- **Newsletter**: Working email validation with demo confirmation state.
- **Interactive Local Cart Drawer & Quickview**: Add/remove confections, view subtotal, and inspect ingredients and shelf life.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
The application will be accessible at `http://localhost:3000`.

### Production Build
```bash
npm run build
```
